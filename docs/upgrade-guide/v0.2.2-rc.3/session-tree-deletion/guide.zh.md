# 会话删除范围

[English](guide.md) | 中文

## 变更

以前，有依赖会话的会话无法删除。现在，经确认的客户端操作和 `WorkspaceRegistry.deleteSession` 会先删除后代会话，再删除父会话，包括子代理会话和派生分支。如果任何会话仍在运行，则在删除任何历史之前拒绝操作。项目文件保留在磁盘上。

客户端删除工作区时现在传递 `deleteSessions: true`。直接调用工作区删除 API 时，省略此选项仍只删除注册信息。如果工作区有组外依赖会话，则拒绝删除。

## 迁移

1. 更新调用 `deleteSession` 的集成，要求确认删除父会话和所有后代历史。不要使用此操作来仅删除父会话而保留子会话。
2. 工作区 API 调用省略 `deleteSessions` 可保留会话历史；只有确认永久删除后才将其设为 `true`。
3. 使用临时会话树验证删除后重启，父会话和后代都不再出现在列表中。项目文件应位于会话存储之外；删除操作会保留这些文件。

无需迁移会话格式。如果 I/O 错误中断删除，已删除的历史不会恢复；解决错误后可重试。
